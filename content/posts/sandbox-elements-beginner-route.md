## Build a clean first-session laboratory

Treat the empty board as a controlled workspace, not a canvas to fill. Reserve one area for the element being tested, one for the second input, and one empty strip where they can meet. Small samples make it easier to see whether movement, heat, or direct contact caused a result. If the board becomes crowded, reset before drawing a conclusion; a hidden third material can turn a simple pair into a different experiment.

Before combining anything, place each visible starter element alone and watch how it behaves. Note whether it falls, flows, rises, spreads, burns, cools, or remains fixed. The official description establishes that elements have physical behaviors, so this baseline is part of the answer. It lets a new player predict where contact will occur and prevents a missed reaction from being blamed on a recipe that never actually touched.

## Use a low-risk unlock sequence

Start with pairs whose movement makes the contact easy to observe. Draw one input, pause, then introduce the second at a single boundary. Keep the rest of the board empty. The goal is not to guess a long secret chain; it is to produce one readable result and learn how the game signals discovery. ## Recover when the expected discovery does not appear

A failed attempt has four common explanations: the materials never contacted, too much of one input destroyed the other, an existing material contaminated the boundary, or the current build uses another condition. Clear the area and repeat at a smaller scale before changing ingredients. If the result still differs, reverse the placement order and record both attempts separately; do not silently merge them into one claim.

Stop after two clean attempts with the same setup. Continuing to redraw the same pair on a contaminated board does not increase confidence. Mark the combination unverified for this session and move to another visible pair. This stop rule protects the player from wasting time and protects the site from publishing a guessed unlock sequence as fact.
